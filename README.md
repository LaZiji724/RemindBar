# 提醒条

macOS 菜单栏提醒 App（原生 Swift / SwiftUI，零第三方依赖，苹果系统风格）。

> **v1.0** · 需要 macOS 15 或更新版本 · App 叫“提醒条”，仓库名用英文 `RemindBar`（GitHub 不支持中文仓库名）。

- **一句话添加提醒**：输入或口述“去睡觉，今晚19点”，自动拆成「事件 / 日期 / 时间」。`19:00`、`19：00`、`19点`、`下午7点`、`七点半`、`明晚8点`、`周五前`、`半小时后` 等写法都能读懂。
- **语音口述**：面板里的麦克风按钮（⌘D）。默认用本机离线识别（音频不出这台 Mac、不保存），识别结果先显示出来，你看一眼再回车。
- **自动盯作业 DDL**：连接 **同济 Canvas**、**课堂派**，或任意网课网页。你自己登录一次，之后提醒条定时读取新作业和截止时间，临近截止时在菜单栏弹出面板并发系统通知。
- **DeepSeek 只在需要时才用**：只允许 `deepseek-flash`、关闭思考；本地规则能读懂的，一个 token 都不花。

## 使用

1. 点菜单栏的铃铛，在输入框里写或点麦克风说。输入时会实时显示它怎么理解（事件 / 日期 / 时间），不确定的地方会提示，并给出“改为…”的一键切换。回车添加。
2. 到点（以及作业截止前 1 天、3 小时、30 分钟）会弹系统通知；App 在运行时还会自动展开面板。
3. 设置 › **监控源** › 连接课堂派 / 同济 Canvas：弹出登录窗口，你自己登录（密码、验证码、扫码都行），提醒条不会看到也不会保存你的密码。
4. **网站来的待办没有手动“完成”按钮，也不能手动删除**，是否完成以网站为准：你在网站上交了作业（或在 Canvas 里勾选完成），下一次读取时它就自动完成；网站上又变回未完成，会重新打开。删掉一个网站还开着的作业，等于悄悄藏起一个截止时间，所以不给这个按钮。Canvas 只读“两周前到半年后”的窗口，逾期超过 15 天、网站已不再列出的老条目会自动移出列表。
   面板右上角的 ↻ 每按一次都会**立刻去网站重新读取**（不等定时、不走缓存），读完在面板里告诉你每个网站有什么变化，没变化也会说。另外打开面板时如果距上次读取超过 5 分钟、以及每 30 分钟（可调）也会自动读一次。
   自己加的提醒仍然用圆圈手动完成、可以删除；通用网页监控的条目网站说不清是否完成，也保留手动完成和删除（删掉的不会被再次读回来）。
5. 设置 › **AI** › 粘贴 DeepSeek Key（只存钥匙串）。点“测试连接”只查余额和模型，不花 token。

> 通知要在“系统设置 › 通知 › 提醒条”里允许；面板里如果出现橙色的“系统通知被关闭了”，点它直接跳转。

## 忽略与提醒事项同步（2026-10-27 新增）

- **忽略**：Canvas、课堂派来的作业不能删除，但可以“忽略”（悬停按钮或右键菜单）：不再提醒、不计入待办，仍被跟踪；网站标记完成、不再列出，或网站把它重新打开时自动结束忽略。面板底部“已忽略 N”和 设置 › 监控源 里都能一键恢复，忽略后 6 秒内可撤销。
- **与 Apple 提醒事项双向同步**（面板顶部有“同步到 Apple 提醒事项”的提示，点“开启同步”即可，也可以在 设置 › 提醒事项 里开关；第一次会弹系统授权）：提醒条里的提醒写进“提醒事项”App 的「提醒条」列表，在那边新增、改标题或时间、勾选、删除都会同步回来；第一次开启时，如果默认的“提醒”列表里未完成的不超过 30 项，会一并同步（Siri 和手机上默认新建的提醒就会进来）；其它列表可在设置里勾选。
  - 每一对提醒记着“上次两边一致时的值”，改动按字段三方合并；网站作业的副本是单向镜像（网站说了算，在提醒事项里勾选或修改不影响提醒条）。
  - 一次推断出的删除超过 max(3, 一半) 时暂停删除并警告，两边都保留并互相补齐。
  - 不导入有重复规则的提醒事项；副本默认带到点闹铃（可关），Mac 上到点会和提醒条各响一次。
  - 同步引擎有离线测试（用内存版提醒事项）；真实的读写用 `RemindBar --apple-selftest` 在一个临时列表里真机自检过（建列表、写入、改、勾选、删除、忽略与恢复，结束后自动删掉临时列表）。
  - 要用时到 设置 › 提醒事项 打开开关；每次重新构建 App 后，系统会要你重新允许一次访问提醒事项。

## 下载安装（发布版）

在 GitHub 的 Releases 里下载 `RemindBar-v1.0-macOS.zip`，解压后把“提醒条”拖进“应用程序”。这个版本用本机临时签名、没有经过苹果公证，第一次打开请**右键 › 打开**（或在“系统设置 › 隐私与安全性”里点“仍要打开”）。首次使用时系统会按需询问：通知、麦克风、语音识别、提醒事项。

## 自测

`swift run remind-selftest` 离线运行（约 2000 项检查，不联网、不花 token）：解析器（含 24 小时 × 多种写法的穷举）、语音会话状态机、调度、存储、DeepSeek 请求体与响应校验、熔断、预算、缓存、Canvas 解析与同步对账、网页监控的省 token 规则。

```bash
DEEPSEEK_API_KEY=你的key swift run remind-selftest --live
```

`--live` 会发出约 2 次很小的真实请求（总共不到 1000 token）：查余额、列模型、解析一句话，并断言 `reasoning_tokens == 0`、`finish_reason == stop`、命中缓存不重复计费。

其它开发用命令（都在打包后的 App 上运行）：

| 命令 | 作用 |
|---|---|
| `RemindBar --snapshot <目录>` | 用演示数据把面板和设置页渲染成 PNG（不需要屏幕录制权限） |
| `remind-selftest --parse "文字"… [--now "2026-10-26 21:05"]` | 看解析器怎么读一句话 |
| `RemindBar --ui-smoke <结果文件> --data-dir <目录>` | 在真实 App 里模拟点图标、输入、回车、到点弹出面板 |
| `RemindBar --voice-file-test <结果文件>` | 用 `say` 合成中文语音，交给真实的离线识别器，再看解析结果 |
| `RemindBar --test-web-fetch <结果文件>` | 检查隐藏网页读取通道是否可用 |
| `RemindBar --canvas-crosscheck <结果文件>` | 只读：用已登录的会话，把 Canvas 的 planner、待办接口、各课程作业列表三种读法做对比 |
| `RemindBar --ketangpai-check <结果文件>` | 只读：把课堂派待办与本学期各课程作业列表做对比 |
| `RemindBar --probe-speech` | 本机中文离线识别是否可用 |
| `open -n -W -a 提醒条.app --args --apple-status <结果文件>` | 只读：列出提醒事项里各列表的未完成数，以及「提醒条」列表里的内容 |
| `RemindBar --enable-apple-link` | 启动后直接开启与提醒事项的同步（等同设置里的开关） |
| `open -n -W -a 提醒条.app --args --apple-selftest <结果文件>` | 在真实的“提醒事项”里建临时列表，跑完整套同步读写并清理（需在系统弹窗里允许一次） |
| `RemindBar --store-deepseek-key` | 从环境变量 `DEEPSEEK_API_KEY` 把 key 写入钥匙串（不打印） |

## DeepSeek 用量规则

- 模型固定 `deepseek-flash`，请求只带 `"thinking":{"type":"disabled"}`，不发任何其它模式开关；源码里出现别的模型名，自测会失败。
- 每次响应都会校验：`finish_reason == stop`、内容非空且是合法 JSON、字段通过校验器；发现 `reasoning_tokens > 0` 或 `reasoning_content` 就**熔断**：停用所有 AI 调用并提示，需要你在设置里手动恢复。
- 重试最多 1 次，只针对限流 / 服务器错误 / 网络错误 / 空内容；key 无效或余额不足不重试，直接停用并提示原因。
- 预算：默认每天 20k、每月 300k tokens（可调）；每个监控源每天最多 6 次 AI；连续 3 次读不到新作业，该源的 AI 暂停 24 小时；相同内容 30 天内直接用缓存。
- 什么时候才会花 token：①本地规则看不懂的句子（打字需点“用 AI 解析”，口述默认自动）；②网页监控里“有变化 + 含作业/日期词 + 本地读不懂”的**新增**行。课堂派 / Canvas 的数据来自结构化接口，**0 token**。

## 数据与隐私

- 数据在 `~/Library/Application Support/RemindBar/`（`state.json` 提醒与监控源，`ai-usage.json` 用量，`ai-cache.json` 缓存），原子写入并保留上一版备份。
- DeepSeek Key 只存钥匙串；网站登录状态在 WebKit 自己的存储里，提醒条只读取，不存密码。
- 对学校网站**只读**：不提交、不勾选、不在网站上忽略待办（提醒条里的“忽略”只在本机生效）。课堂派适配器的接口白名单里只有读取待办的路径。
- 语音默认只在本机识别，不保存录音；只有你在设置里允许、且语言没有离线包时才会用 Apple 服务器。

## 已知限制

- 暂不支持循环提醒（“每周一…”会按最近一次创建并提示）。
- 课堂派的接口没有公开文档，适配器是根据课堂派网页自己的请求校准出来的；如果课堂派改版导致读不出来，用 设置 › 监控源 › 高级 › 校准课堂派接口 重新记录一次样本即可（用完请点“删除校准样本”）。
- 课堂派只能读到有截止时间的作业；没设截止时间的作业没法提醒，会被跳过。
- 登录过期时只会通知一次，需要到设置里重新登录。
